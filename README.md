# XmasWelcome

Plugin pro Paper 26.2 (Java 25).

- **Uvítání:** při připojení pošle hráči do chatu uvítací text (config `welcome`).
- **Double jump:** ve světě `Christmas` (dá se změnit v configu) se hráči odrazí dvojitým mezerníkem, do chatu se napíše hláška. Platí pro survival a adventure.
- **Knížka:** ve světě `Christmas` mají hráči ve středním slotu hotbaru knížku s informacemi o serveru (text si upravíš v configu, `book.pages`). Nejde přesunout ani zahodit a po opuštění světa zmizí.

Příkaz: `/xmaswelcome reload` (OP) načte config bez restartu.
Oprávnění: `xmaswelcome.doublejump` (default všichni), `xmaswelcome.admin` (default OP).
